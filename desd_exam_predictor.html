Unit I Verdict

Fastest unit with highest marks-per-hour. K-Map and Quine-McCluskey are guaranteed in every paper. Always pair K-Map answers with universal gate (NAND/NOR) implementation. 2's complement is a safe Part A pick.

K-Map Simplification (4-variable SOP + POS)
92%
92%
Medium2.5hProblem-solving
Appeared in ALL 3 end-sem papers + 2 internals. Always Part B 13m, often paired with universal gate implementation. Nov/Dec 2025: SOP+POS with NOR gates. Nov/Dec 2024: K-Map + NAND/NOR. Assessment 1: SOP+POS with NOR. THE safest scoring question.
Most probable questions

Unit II Verdict

BCD→XS-3 is the most repeated combinational question across all papers. CLA adder and magnitude comparator are always in Part B. MUX-based function implementation is a near-certain Part A. The squaring circuit (Part C, Nov/Dec 2025) tests design fundamentals at the highest BL level.

Unit III Verdict — Highest Marks Unit

Contributes the most marks across all papers. Counter design with JK/T FF is virtually guaranteed at 13m. Sequence detector is always in Part B or Part C. State minimisation pairs with almost every synchronous design question. Flip-flop excitation tables underpin every question here — know them cold.

Unit IV Verdict — Hardest Unit, But Predictable

Two question types dominate EVERY paper: (1) Primitive Flow Table from a word problem, and (2) Race-free state assignment for a given flow table with logic circuit. Learn these two procedures thoroughly. Hazard identification (static-1 vs static-0) appears in Part A and B consistently. The examiner recycles the same flow tables across papers.

Topics — click to expand
1
Primitive Flow Table Design (word problem)
88%
88%
Hard3hConcept + Problem-solving
Nov/Dec 2025 (13m), May/Jun 2025 (13m), Nov/Dec 2024 (13m), Internal Assessment 2 (12.5m). Most consistent Unit IV question. Word problem describes input/output conditions — draw primitive flow table then reduce using implication table. GUARANTEED Part B question every paper.
Most probable questions
  • 13mTwo inputs X,Y; output Z. Initially Z=0. Z→1 when XY=11 only if X=1 before Y. Z stays 1 until X→0. Draw primitive flow table, reduce using implication table.
  • 13mInputs X1,X2; outputs Z1,Z2. When X1X2=00: Z1Z2=11. When X1=1 and X2 changes 0→1: Z1Z2=01. When X2=1 and X1 changes 0→1: Z1Z2=10. Construct primitive flow table.
  • 13mLogic system X,Y inputs, Z output. Initially 0. Z=1 when XY=11 but only if X=1 before Y; Z stays 1 till X→0. Draw primitive and reduced flow table.

Race-Free State Assignment + Logic Circuit

85%

Procedure: identify critical races → assign binary codes → derive transition table → excitation/output equations → logic circuit. Same flow tables appear across papers!
Most probable questions

  • 13m3-state flow table (a=00, b=11, c=01) — assign 4th state to avoid critical races, derive transition table, draw logic diagram.

Unit V Verdict — Easiest 13-Mark Question In The Entire Paper

CMOS circuits are mostly drawing + transistor ON/OFF table. It's the best marks-per-effort question in the paper. PAL and PLA appear with equal frequency. The examiner reused the EXACT same PAL functions (f1, f2, f3) across Nov/Dec 2024 and Nov/Dec 2025. Noise margin is a repeat Part A question every paper.
