Most probable 16-mark questions

  • 1.Consider the AM signal s(t) = A[1 + k_a m(t)]cos(2πf_c t). Identify carrier and message signals. Derive the spectrum and plot it. Design an envelope detector for demodulation. (Based on 2024, 2025 pattern)
  • 2.Derive the time-domain and frequency-domain expression for SSB-USB in terms of m(t) and its Hilbert transform. If m(t) = 2cos(300πt) and c(t) = 50cos(8000πt), write the SSB-USB expression and draw the spectrum. Explain Costas loop demodulation. (2024 exact pattern)
  • 3.Three amplifiers A, B, C with gain and noise figures are connected in cascade. Determine overall noise figure and equivalent noise temperature for order B-A-C and compare with A-B-C. (2025 End Sem exact)

Most probable 8-mark questions

  • 1.Explain the generation of AM signal using switching modulator (square law or ring modulator). Draw the spectrum and compute power efficiency.
  • 2.Discuss demodulation of DSB-SC signals using coherent receiver. Draw spectrum of input and output when phase difference is 0° and 45°.

Most probable 16-mark questions

  • 1.A DMS emits symbols {A,B,C,D,E,F} with probabilities {0.15, 0.2, 0.15, 0.25, 0.05, 0.2}. Apply Huffman coding algorithm and generate the dictionary of code words. Determine the coding efficiency. (2024 exact)
  • 2.Consider a DMS emits symbols {A,B,C,D,E,F} with probabilities {0.1, 0.25, 0.15, 0.2, 0.1, 0.2}. Using Shannon-Fano coding algorithm, generate code words. Determine coding efficiency. (2025 exact)
  • 3.Consider the binary channel given with P(x1)=P(x2)=0.5. Find: (a) channel transition matrix (b) probabilities P(y1) and P(y2) (c) joint probabilities P(x2,y1) and P(x1,y2). (2025 exact — 13 marks)

Part C (15 marks) compulsory question prediction

Part C prediction (Q.No. 16 is compulsory)
Pattern: Part C is a combined multi-part problem testing 2–3 units together.

2022 pattern: FM spectrum (8 marks) + FM-to-FM conversion scheme (7 marks)
2024 pattern: Video source entropy + NRZ/Manchester waveform + Shannon channel bandwidth
2025 pattern: Cascade amplifier noise figure (8 marks) + PCM quantizer SNR (7 marks)

Most probable 2025–26 Part C: FM wideband spectrum numerical (Bessel) + PCM/source coding combined problem, OR noise figure cascade + Shannon capacity problem. Prepare FM + PCM numericals as priority for Part C.
